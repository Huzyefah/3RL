# Sentinel for NovaPay (PS-02)

Sentinel is an agentic AIOps system for **NovaPay**, a fictional Pakistani digital-payments platform. It predicts payment-impacting incidents before they breach, uses an adversarial Skeptic agent to argue false alarms down, writes grounded root-cause summaries, and takes policy-gated preventive actions, one of which visibly fixes a live fault.

**Pitch:** on the PS-02 data, a static threshold catches 0 of 28 incidents, and the 95% rule that catches all 28 is wrong 44% of the time (precision 0.56). Sentinel adds context: it warns earlier, argues away the noise, and arrives with the cause and the fix.

## Quickstart

Docker:

```bash
cp .env.example .env        # set OPENAI_API_KEY
docker compose up --build
# open http://localhost:3000
```

Local dev:

```bash
uv sync && uv run uvicorn sentinel.api.main:app --port 8080
cd frontend && npm run dev
```

Without an OpenAI key the agents fall back to a deterministic template path, so the demo still runs.

## Demo flows

1. **08-01 cascade replay**: PaymentGateway ETA counts down, the Skeptic disputes, the Commander re-plans and routes to the right team with a grounded RCA.
2. **Salary-day false alarm suppressed**: every signal ramps, the Skeptic cites the calendar, and the "FP avoided" counter increments.
3. **Break BANK_C, approve reroute, recovery**: inject `bank_c_slow`, approve the reroute in the approval queue, watch success recover live and the Commander verify and close.

## Honesty note

The PS-02 rows are real and kept unaltered. Dense data between anchors is generated by a seeded, committed generator and is labelled **synthetic replay** in the UI. NovaPay is fictional; no real company is impersonated.

## Tech stack

Python 3.12, FastAPI, SSE, pydantic; OpenAI API (only LLM provider) with deterministic fallback; Next.js frontend; Docker Compose; GCP target (Cloud Run, Pub/Sub, BigQuery, Secret Manager, Cloud Scheduler) described in `docs/ARCHITECTURE.md`.
