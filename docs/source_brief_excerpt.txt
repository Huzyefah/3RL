PROBLEM STATEMENT PS-02
Proactive Anomaly Detection & Issue Prevention Agent
Difficulty: Hard    |    Category: AIOps / Observability
The Problem
Enterprise support teams operate reactively — they wait for users to report problems. By the time a ticket is filed, the user has already been impacted. Many issues leave early signals: rising error rates, latency spikes, unusual usage patterns, or failed authentication attempts. These signals go unmonitored or are buried in dashboards nobody watches.
Your Challenge
Build an agentic AI system that continuously monitors application telemetry (logs, metrics, traces), detects anomalous patterns before they become incidents, and autonomously triggers preventive actions — such as alerting on-call teams, scaling infrastructure, or creating pre-emptive support tickets with root-cause hypotheses.
Technical Requirements
Real-time ingestion of metrics, logs, and event streams
Anomaly detection using statistical and LLM-based reasoning
Autonomous action execution: alerting, ticket creation, suggested runbook steps
Natural-language incident summaries generated for on-call engineers
Historical pattern correlation: link current anomalies to past incidents

Suggested GCP Tech Stack
Vertex AI, BigQuery, Cloud Monitoring API, Pub/Sub, Cloud Functions, Gemini for summarization
Sample Dataset
ps02_system_telemetry.csv — 500 synthetic telemetry records with metrics, thresholds, and incident flags
Evaluation Criteria
Detection lead time (how far ahead of incident), false positive rate, quality of generated root-cause summaries
