Solution flow

Replay / sim -> Detector -> Grouping -> Agents (Skeptic, Commander) -> Policy Guard -> Actions -> Verify

Detector: Holt ETA, EWMA, binomial segment tests. No LLM in detection.

Agents

  • Commander: plans, uses data tools, writes grounded RCA, proposes action, verifies outcome.
  • Skeptic: argues the alert is a false alarm using calendar, topology and cascades.
  • OpenAI-backed, with a deterministic fallback.

Safe autonomy

  • Policy Guard: allow, require approval, or deny.
  • Reroute needs approval and a healthy target; audited and reversible.
  • Ledger and limit changes are denied outright.
